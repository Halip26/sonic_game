# This is a simple Sonic game made with Python and Pygame

The game features a basic level where the player controls Sonic, collecting rings and avoiding obstacles. The objective is to reach the end of the level while achieving a high score

## Installation

1. Make sure you have Python installed on your system.
2. Install the required dependencies by running:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the game by executing:

   ```bash
   python main.py
   ```hon main.py
   ```
