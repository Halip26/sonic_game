# Sonic Game

A simple 2D platform-style game inspired by Sonic, built with Python and Pygame. The player controls Sonic through a scrolling level, jumps over obstacles, avoids hazards, and tries to earn a high score.

## Features

- Side-scrolling gameplay inspired by classic arcade-style runners
- Jump and duck controls
- Obstacles such as cacti and birds
- Score tracking and high-score display
- Background music and sound effects

## Requirements

- Python 3.8+
- Pygame

## Installation

1. Clone or download this repository.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:

   ```bash
   python main.py
   ```

## Controls

- Space or Up Arrow: Jump
- Down Arrow: Duck
- Escape: Exit the game over screen
- Enter or Space: Restart after game over
